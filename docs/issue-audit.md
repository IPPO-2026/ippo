## 이번 수정

- `test:ui:live-contract`의 브라우저에서 서비스 워커를 차단했다. 모의 경로가 새로고침 뒤에도 적용되어, 모의 결제 확인 요청이 운영 서버로 빠져나가는 것을 막는다. 실제 서비스 워커는 별도 PWA 검사에서 유지한다. 브라우저도 실패 시 `finally`에서 종료한다.
- UI 회귀 검사에 저장 해제 후 새로고침 및 한국어+일본 지역 / 일본어+한국 지역을 추가했다.
- CI에 UI·모의 live 계약 검사와 평가 데이터 준비 검사를 포함했다.
- 현재 없는 에너지 선택·자정 미션 교체·내보내기 및 기본 미션 저장 설명을 제품·아키텍처·개인정보·로드맵에서 바로잡았다. 결제 복귀 임시 저장과 테스트 주문 범위도 반영했다.
- 합성 평가 세트 준비는 네트워크·모델 호출 없이 가능하다. 응답과 점수는 `pending`으로 남긴다.
