# IPPO 설치형 앱

IPPO는 하나의 웹 주소로 일본·한국에서 사용하는 PWA입니다. 앱스토어 등록 없이 홈 화면에 추가할 수 있습니다. 현재 [공개 앱](https://ippo.hyscodebase.workers.dev)에 실제 AI가 연결되어 있습니다. 재배포는 [배포 가이드](deployment.md)를 참고합니다.

## 홈 화면 설치

먼저 HTTPS 배포 주소를 휴대폰에서 엽니다. `127.0.0.1`은 개발 컴퓨터 자체 주소이므로 휴대폰에 전달하는 서비스 주소가 아닙니다.

- iPhone/iPad: Safari에서 공유 → 홈 화면에 추가 → 추가.
- Android: Chrome에서 앱의 설정 → 홈 화면에 설치. 버튼이 없으면 브라우저 메뉴의 앱 설치/홈 화면에 추가를 사용합니다.
- 데스크톱: 지원 브라우저의 주소창 설치 아이콘 또는 앱 설정의 설치 버튼.

브라우저·OS에 따라 메뉴 이름과 설치 지원이 다릅니다. 앱 설정에는 한국어·일본어 설치 안내가 있습니다. 실제 설치 완료 이벤트 또는 독립 실행 모드를 확인하기 전에는 설치 완료로 표시하지 않습니다.

## 오프라인과 개인정보

한 번 온라인으로 열어 화면 저장이 끝난 뒤 오프라인에서 앱을 다시 열 수 있습니다. 설정에서 준비 상태를 확인합니다. 대화 속 미션은 저장 선택 시 대화와 함께 기기에 남습니다. 오프라인에서도 저장한 미션을 완료할 수 있습니다. 대화는 기존 설정대로 기본 메모리 보관이며, 기록 저장에 동의한 경우에만 새로 열었을 때 남습니다. 브라우저가 저장 공간을 정리하면 오프라인 데이터가 사라질 수 있습니다.

서비스 워커는 빌드에 포함된 HTML·CSS·JS·로고·아이콘만 저장합니다. `/api/*`, POST 요청, AI 응답, Turnstile은 캐시하지 않습니다. 오프라인에서는 전송 버튼을 막고 연결 안내를 표시합니다. 연결 복구 시 설정을 다시 확인하며 메시지를 자동 재전송하지 않습니다.

## 업데이트

새 버전은 백그라운드에서 준비한 뒤 업데이트 버튼을 표시합니다. 자동 새로고침하지 않습니다. 대화나 초안이 있으면 확인 후 적용하며 보관이 필요하면 기기 저장을 켜거나 필요한 내용을 복사합니다. 저장에 동의하지 않은 대화와 초안은 재실행으로 사라집니다.

## 개발과 검증

```bash
npm run build
npm run dev:api
# 별도 터미널, 로컬 Worker 화면/기능 확인
npm run test:ui
# 별도 임시 서버를 자동 시작하는 PWA 검증
npm run test:pwa
```

서비스 워커는 프로덕션 빌드에서만 등록됩니다. Vite 개발 화면에서는 등록하지 않습니다. 모바일은 안전 영역을 포함한 상단 메뉴와 입력창, 대화 스크롤 영역, VisualViewport 기반 입력 영역을 사용합니다. 실제 iOS/Android 키보드·홈 화면 설치·백그라운드 복귀는 배포 후 실기기 확인이 필요합니다.
