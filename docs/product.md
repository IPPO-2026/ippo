# 잇포 · IPPO · いっぽ — 제품 범위

기준일: 2026-09-19. 이 문서는 제품 결정과 초기 수용 기준을 기록한다. 공개 서비스 출시나 실증 효과를 입증하는 문서가 아니다.

## 제품 정의

**잇포는 한국어와 일본어로 가볍게 이야기하고, 오늘 가능한 작은 행동 한 가지를 골라보는 AI 대화 앱이다.** 일본어 `いっぽ（一歩）`의 한 걸음이라는 의미를 담는다. 브랜드·상표 사용 가능성은 별도 확인 대상이다.

주 사용자는 일본 또는 한국에서 자신의 속도로 일상을 이어가고 싶은 사람이다. 초기 파일럿은 **만 18세 이상 성인**을 대상으로 제안하며, 실제 모집 전에 대상·동의 절차를 확정한다. 사회적 고립의 진단 여부나 치료 필요성을 판정하지 않는다.

핵심 경험은 `언어·이용 국가 선택 → 짧은 대화 또는 에너지 선택 → 작은 미션 → 수락·연기·완료 → 다음에 다시 시작`이다. 대화나 행동을 강제하지 않고, 연기·미완료를 실패로 표시하지 않는다. 대화 시간을 늘리는 것보다 사용자가 부담 없이 다음 행동을 선택할 수 있는지를 살핀다.

## 첨부 기획서와의 관계

사용자가 제공한 「곁걸음 GYEOT STEP 기능명세서, 2026-09-19」를 배경 자료로 참고했다. 원안은 비대화형 탁상 디바이스와 기관 프로그램을 중심으로 하며, 이번 요청의 **한국·일본 AI 채팅 앱**을 우선하여 아래와 같이 범위를 조정한다. 원안 전체를 구현했다고 해석하지 않는다.

| 원안 요소 | 잇포 초기 버전 결정 | 이유·후속 조건 |
|---|---|---|
| 곁걸음 / 이치방 명칭 | 잇포 · IPPO · いっぽ 사용 | 사용자 요청 반영 |
| 감정 대화 없는 탁상 디바이스 | 한국어·일본어 AI 텍스트 대화 중심 모바일 웹 | 사용자가 요청한 새 제품 방향 |
| 에너지 1~5와 하루 한 개 미션 | 검토 가능한 고정 미션 목록과 수락·연기·완료 | AI 응답 품질과 미션 안전성 검증 분리 |
| 사진·영상·활동 데이터 인증 | 증빙 없는 본인 완료만 초기 제공 | 업로드·민감정보·운영 부담 축소 |
| 동료 확인·미션 릴레이·익명 서클 | 후속 검토 | 계정·공유 동의·신고·운영 인력 선행 |
| 보호자·지원자 도움 요청 | 국가별 공식 도움 안내 링크 | 현재 지원자 연결이나 요청 전송 기능 없음 |
| 기관 관리자와 성과 대시보드 | 후속 검토 | 역할별 권한, 기관 분리, 동의 철회 설계 필요 |
| 한국 실증 후 일본 확장 | 초기 UI부터 한국어·일본어 및 국가 선택 | 두 지역 사용성을 함께 점검하되 실증 성공으로 간주하지 않음 |
| 진단·치료·자동 위기 판단 제외 | 유지 | 일상 동행의 범위 유지 |

## 초기 버전 수용 기준

| 영역 | 수용 기준 |
|---|---|
| 언어와 국가 | UI 언어 `ko/ja`와 이용 국가 `KR/JP`를 선택한다. 일본에서 한국어 UI 사용도 가능하다. 언어로 국적이나 위치를 추정하지 않는다. |
| 대화 | 사용자·AI 메시지를 구분하고 전송 중·실패·한도 도달 상태를 표시한다. 중복 전송을 방지한다. |
| 데모 | 외부 AI를 설정하지 않은 기본 모드는 미리 작성한 응답을 반환하며, 데모임을 화면에 명확히 표시한다. |
| 실제 AI | 외부 처리 안내와 명시적 동의 후에만 전송한다. 운영 설정과 Turnstile 검증이 준비된 환경에서만 활성화한다. |
| 입력 제한 | 메시지당 최대 1,000자, 전송 문맥 최대 8개 메시지·합계 3,200자. 긴 대화 전체를 무제한 전송하지 않는다. |
| 미션 | 에너지 1~5에 맞는 작은 미션과 예상 시간을 제시한다. 수락·연기·완료는 본인이 선택한다. 경쟁 순위나 연속 출석 불이익이 없다. |
| 날짜 | 일본은 `Asia/Tokyo`, 한국은 `Asia/Seoul`의 현지 날짜로 오늘의 미션을 구분한다. API 사용량 날짜와는 별개다. |
| 기록 | 대화는 기본적으로 브라우저 메모리에 두고, 대화 기기 저장은 명시적으로 선택한다. 오늘의 에너지·미션·상태·날짜는 기본적으로 해당 브라우저에 저장하며 화면에서 알린다. 내보내기와 모든 기록 삭제 경로를 제공한다. |
| 도움 | 두 국가의 공식 도움 안내에 접근할 수 있다. 연결 대상과 외부 페이지 이동을 명확히 표시한다. |
| 접근성 | 모바일과 데스크톱에서 가로 넘침 없이 사용하고 키보드 조작·입력 라벨·읽기 쉬운 대비를 확인한다. |

수용 기준은 검증해야 할 항목이다. 실제 통과 여부와 배포 상태는 저장소의 검사 결과 및 릴리스 기록으로 확인한다.

## 대화와 미션의 원칙

- 상대를 진단하거나 상담 전문가로 자칭하지 않는다. 생활 속 작은 선택을 존중하는 짧은 답변을 지향한다.
- 사용자의 거절·휴식·연기를 받아들인다. 죄책감, 연속 출석 압박, AI와의 독점적 관계를 유도하지 않는다.
- 신체 활동과 외출은 선택 사항이다. 건강 상태·거주 환경·날씨에 맞지 않으면 다른 행동이나 휴식을 고를 수 있다.
- 모델이 생성한 제안과 앱의 고정 미션을 구분한다. AI 응답이 미션 완료 상태를 변경하지 않는다.
- 한국어와 일본어의 존대·거리감·부담 표현은 각 언어를 이해하는 사람이 검토한다. 번역 제공 자체를 문화적·임상적 적합성 검증으로 간주하지 않는다.

## 초기 범위 밖

로그인, 계정 복구, 기기 간 동기화, 서버 대화 보관, 결제, 음성·사진·영상 업로드, 디바이스 연동, 동료 피드·DM·릴레이, 기관 관리자 화면, 지원자 알림, 자동 위험도 분류는 제공 범위에 포함하지 않는다. 후속 개발은 [로드맵](roadmap.md)의 조건을 충족한 뒤 개별적으로 결정한다.

실제 서비스 호스팅과 실제 모델의 한국어·일본어 품질·안전성 평가는 아직 완료된 것으로 표시하지 않는다. 무료 사용은 제공사 계정 한도 안에서만 가능하며, [아키텍처](architecture.md)와 배포 문서의 제한을 따른다.
