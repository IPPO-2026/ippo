# IPPO 브랜드 적용 기준

사용자가 제공한 공식 로고를 중심으로 화면을 정리한다. 밝은 민트, 넉넉한 여백, 읽기 쉬운 글자와 일관된 아이콘을 사용한다. 기존 캐릭터·세피아 색상·세리프 글꼴은 이 방향에 포함하지 않는다.

## 원본 자산

| 자산 | 프로젝트 경로 | 용도 |
|---|---|---|
| 공식 벡터 워드마크 | `public/brand/ippo-wordmark.svg` | 헤더와 브랜드 소개 영역 |
| 공식 래스터 심벌 | `public/brand/ippo-symbol.png` | 대화 아바타, 정사각형 아이콘 영역, favicon |

두 원본은 변경하지 않고 보관한다. 벡터 워드마크는 `1200 × 600`의 **2:1 비율**을 유지한다. 심벌은 원본 가로·세로 비율을 그대로 사용하고 정사각형 영역 안에 맞춘다. `object-fit: contain`과 충분한 여백을 사용하며 늘리기, 잘라내기, 다시 그리기, 필터로 색 바꾸기를 하지 않는다. 로고 안의 여백도 원본의 일부다.

추가로 받은 래스터 워드마크는 시각 참고 자료다. 저장소에 중복본을 반드시 포함할 필요는 없다. 제공된 벡터와 래스터 사이에 색이나 형태의 미세한 차이가 있을 수 있으며, **UI 브랜드 색은 공식 SVG의 `#66E8BF`를 기준**으로 삼는다. 차이를 보정하려고 원본 로고를 재가공하지 않는다.

## 색상과 가독성

| 역할 | 색상 | 적용 |
|---|---|---|
| 브랜드 민트 | `#66E8BF` | 주요 브랜드 영역, 강조 면, 선택 상태 |
| 차콜 | `#142C27` | 본문, 제목, 민트 배경 위의 글자 |
| 짙은 청록 | `#08755E` | 흰색 배경 위의 작은 강조 글자·링크·아이콘 |
| 기본 바탕 | 흰색·옅은 오프화이트 | 대화 화면, 카드, 설정 화면 |

민트 바탕의 흰 로고는 제공된 원본 그대로 유지한다. 이 조합을 일반 버튼이나 작은 본문 글자에 확대 적용하지 않는다. 색상값으로 계산한 대비는 흰색/민트 **1.52:1**, 차콜/민트 **9.77:1**, 짙은 청록/흰색 **5.65:1**이다. 짙은 청록/민트는 **3.73:1**이므로 민트 위 작은 글자는 차콜을 사용한다. 이 계산은 색 조합의 수치이며, 전체 화면의 접근성 검증을 대신하지 않는다.

## 화면 규칙

- 한국어·일본어 모두 산세리프 계열을 사용한다. 본문은 장식보다 가독성을 우선하고 언어 변경 시 글자 잘림·행간을 점검한다.
- 카드와 입력창의 모서리는 약 `16–20px`로 통일한다. 원형 아바타와 작은 상태 표시처럼 용도가 다른 요소는 별도 형태를 사용할 수 있다.
- 아이콘은 같은 계열의 선 굵기·크기로 맞춘다. 본문과 아이콘은 차콜을 기본으로 하며 브랜드 민트로만 상태를 구분하지 않는다.
- 워드마크는 앱의 정체성을 보여주는 헤더에 사용하고, 반복되는 대화 아바타에는 심벌을 사용한다. 좁은 화면에서 워드마크를 찌그러뜨려 넣지 않는다.
- 의미 있는 로고에는 `IPPO` 대체 텍스트를 제공한다. 같은 이름이 바로 옆에 있어 중복되는 장식 이미지는 중복 읽기를 피한다.
- 모바일·데스크톱에서 로고 비율, 여백, 입력창과 버튼의 읽기 쉬운 대비를 확인한다. 화면 밀도를 낮추되 필요한 설정·도움 경로는 찾을 수 있게 둔다.

이 브랜드 변경은 화면 표현과 자산 정리에 한정된다. 실제 AI 연결, 외부 처리 동의, 사용량 제한, 기록 저장 정책을 바꾸거나 서비스를 배포한 것으로 표시하지 않는다.
