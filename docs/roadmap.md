# 개발 로드맵

기준일: 2026-09-19. 일정 추정 대신 완료 조건으로 단계를 나눈다. 앞 단계의 검증 결과가 다음 단계의 범위를 결정하며, 현재 저장소나 데모 화면이 실제 사용자 실증을 뜻하지 않는다.

## 1단계 — 범위가 명확한 데모

**산출물:** 공개 저장소, 한국어·일본어 모바일 웹, 고정 응답 데모, 에너지와 작은 미션, 로컬 기록 제어, 배포 설정과 운영 문서.

완료 조건:

- 처음 실행하면 데모 상태가 명확하고 유료·실제 모델 호출 없이 핵심 흐름을 확인할 수 있다.
- 언어와 국가를 각각 바꿀 수 있고, 미션의 수락·연기·완료와 다음 날 표시를 확인한다.
- 대화는 메모리 기본·기기 저장 선택으로 동작한다. 오늘의 에너지·미션 상태·날짜는 기기에 기본 저장됨을 안내하며, 모든 기록 삭제 시 대화와 미션을 함께 초기화한다. 내보내기·삭제가 설명과 일치한다.
- 빌드·타입 검사와 API의 잘못된 입력·한도 처리 검사가 통과한다.
- 390px 및 1440px 화면에서 주요 흐름, 가로 넘침, 브라우저 오류, 이미지 누락을 확인한다.
- 공개 저장소에 비밀 키, 개인정보, 실제 대화 원문, 첨부 원본 전체가 포함되지 않는다.

## 2단계 — 제한된 실제 AI 연결

**산출물:** Cloudflare Free 환경, D1 요청량 제한, Turnstile 검증, 실제 모델 응답을 확인한 운영 기록.

완료 조건:

- 배포된 URL에서 실제 AI 응답임을 확인하고 데모와 구분한다. 모델명·설정·검증 날짜를 기록한다.
- 외부 전송 동의가 없거나 Turnstile·D1·필수 비밀 값이 누락되면 AI 호출이 차단된다.
- IP별 6회·전체 60회 일일 제한이 연속·동시 요청에서도 적용된다. 한도 도달 후 사용자가 다음 행동을 이해할 수 있다.
- Workers Free와 Workers AI의 계정 사용량을 확인한다. 다른 앱의 소비량을 포함하고, 유료 자동 전환을 구성하지 않는다.
- 한국어·일본어 검토자가 짧은 대화, 존대·거리감, 거절·연기, 의료적 질문, 긴급 도움 안내 등 준비된 사례를 검토한다.
- 모델이 진단·치료 효과·자동 위기 대응을 약속하는 중대한 결함이 발견되면 공개 AI 활성화를 보류하고 수정 후 재검증한다.
- 국가별 도움 링크, 개인정보 안내, 운영 담당자의 문의 처리 경로와 실제 데이터 처리 조건을 확정한다.

실제 모델을 호출하지 않은 테스트나 모의 응답만으로 이 단계를 완료 표시하지 않는다.

## 3단계 — 동의한 성인과 소규모 파일럿

**산출물:** 확정된 대상과 참여 안내, 사람의 언어·안전 검토 기록, 동의된 최소 데이터에 근거한 사용성 보고서.

초기 제안은 만 18세 이상이다. 모집 인원·기간·운영 가능 시간은 운영자가 정한다. 기관·미성년자 대상 확대는 이 단계의 기본 범위가 아니다.

완료 조건:

- 사용자에게 AI의 역할, 기기 저장, 외부 처리, 삭제, 도움 경로, 서비스 한도를 이해할 수 있는 말로 안내한다.
- 실제 참가자 투입 전 한국어·일본어 표현 검토와 개인정보·국가 간 데이터 처리 검토를 마친다.
- 설문이나 선택적 내보내기 등 별도로 동의한 방법으로만 평가 데이터를 수집한다. 개인 대화 원문 제출을 필수로 만들지 않는다.
- 불편·혼동·전송 실패·부담 유발 사례와 수정 내역을 기록한다. 참여 중단을 실패로 평가하지 않는다.
- 지표의 분모, 제외 기준, 결측을 보고하며 효과를 입증하지 못한 결과도 그대로 남긴다.

## 4단계 — 수요가 확인된 기능만 확장

**산출물:** 파일럿 증거에 근거한 다음 기능의 명세와 운영 책임.

후보는 계정·기기 간 동기화, 동료 확인·미션 릴레이, 기관 프로그램이다. 동시에 모두 구현하지 않고 필요한 기능 하나를 우선한다. 탁상 디바이스, 사진·영상 업로드는 별도 비용·안전·유지보수 검토가 필요한 독립 과제로 둔다.

완료 조건:

- 계정 도입 전 탈퇴·복구·데이터 삭제·접근 제어와 보존 정책을 정한다.
- 동료 기능 전 공유 동의·철회·신고·차단·콘텐츠 검토·운영 대응을 준비한다.
- 기관 기능 전 기관별 격리, 역할별 권한, 동의 철회 반영, 감사 기록을 검증한다.
- 확장 후 예상 비용과 무료 한도 초과 시 동작을 다시 계산한다. 유료 운영 결정은 별도로 한다.
- 원안의 행동 변화 가설을 연구하려면 비교 설계·윤리 검토 등 필요한 절차를 별도 수립한다. 사용성 결과를 치료 효과로 표현하지 않는다.

## 측정할 지표와 해석 범위

현재 서버는 제품 분석 이벤트나 사용자별 대화·미션 이력을 수집하지 않는다. 아래 지표는 **파일럿 평가 설계**이며 기존 D1 요청 카운터에서 계산할 수 있다고 가정하지 않는다. 분모가 0이면 `해당 없음`, 미수집이면 `미수집`으로 표시한다.

| 지표 | 정의 | 해석 주의 |
|---|---|---|
| 미션 수락률 | 미션이 제시된 참여자-일 중 수락한 참여자-일 비율 | 노출 자체를 측정하는 별도 동의 필요 |
| 본인 완료율 | 수락한 참여자-일 중 본인이 완료로 표시한 비율 | 객관적 활동 검증이나 건강 개선 지표 아님 |
| 다음 날 재참여율 | 재참여 관찰이 가능한 참여자-일 중 다음 날 다시 이용한 비율 | 기기 변경·기록 삭제·미응답을 실패로 단정하지 않음 |
| 부담과 통제감 | 휴식·연기·삭제·AI 한계를 이해했는지에 대한 선택적 피드백 | 민감한 자유 답변 수집을 최소화 |
| 대화 품질 | 검토 사례별 언어 적절성·요청 준수·부적절한 주장 여부 | 모델·프롬프트 버전과 언어별 결과를 함께 기록 |
| AI 요청 성공률 | 모델 호출 대상 요청 중 정상 응답 비율 | 한도 차단과 제공자 오류를 구분. 실제 사용자 수와 다름 |
| 무료 사용량 | 계정의 neurons·Worker·D1 사용량과 앱 허용 요청 수 | 같은 계정의 다른 프로젝트 사용량 포함 |

목표값·성과 수치는 아직 설정하거나 관측하지 않았다. 첫 파일럿에서는 측정 가능성과 사용자 부담을 먼저 확인하고, 비교 가능한 기초선이 생긴 뒤 다음 단계 목표를 정한다.
