# 개인정보와 안전 운영 기준

기준일: 2026-09-19. 개발·파일럿 준비를 위한 기준이며, 완성된 개인정보처리방침이나 법률·의료 검토 결과가 아니다. 실제 운영 주체·문의 창구·서비스 설정을 확정한 뒤 사용자 안내를 완성한다.

## 서비스가 하는 일

잇포는 한국어·일본어 대화와 작은 일상 미션을 제공한다. 의료기관·상담자·응급 대응 기관이 아니며 진단, 치료 효과 보장, 자동 위기 분류, 지원자에게 자동 연락을 제공하지 않는다. 현재 도움 기능은 사용자가 직접 열 수 있는 외부 공식 안내다.

초기 성인 파일럿(만 18세 이상)을 제안한다. 연령 기준 안내만으로 신원이나 나이를 검증했다고 표현하지 않는다. 미성년자 대상 운영은 동의와 보호 절차를 별도로 검토한 후 결정한다.

## 데이터 최소화

- 대화는 기본적으로 브라우저 메모리에 둔다. 대화의 기기 저장은 사용자가 명시적으로 선택해야 하며 선택 시 최근 60개 메시지를 보관한다.
- 오늘의 에너지·미션·상태·날짜와 언어·국가·저장 설정은 해당 브라우저에 기본 저장한다. 다음 접속에서 오늘의 한 걸음을 이어가기 위한 정보이며 서버 미션 이력으로 전송하지 않는다. 화면에서 저장 사실을 안내하고 모든 기록 삭제로 대화·미션 기록을 함께 초기화할 수 있게 한다. 브라우저 사이트 데이터를 지우면 저장된 설정도 제거할 수 있다.
- 같은 브라우저를 사용하는 사람이 저장 기록을 볼 수 있음을 안내한다. 브라우저 저장소를 암호화된 개인 금고로 설명하지 않는다.
- 내보내기 전 파일에 대화 내용이 포함됨을 알린다. 내려받은 파일은 사용자가 별도로 관리·삭제한다.
- 앱 서버에 대화 원문·미션 수행 기록 DB를 만들지 않는다. 원문을 애플리케이션 로그나 오류 추적 메시지에 출력하지 않는다.
- 요청량 제한을 위해 날짜와 IP를 비밀 키로 HMAC 처리한 가명화 키·횟수를 D1에 저장한다. UTC 기록일의 이틀 뒤 00:00에 만료되도록 설정하고 예약 작업으로 만료 항목을 정리한다. 가명화는 완전한 익명성과 동일하지 않다.
- 실명, 연락처, 정확한 위치, 사진·영상, 진단명 입력을 기능 사용의 조건으로 요구하지 않는다. 사용자가 대화에 스스로 입력할 수 있으므로 민감한 내용을 보내기 전 주의 안내를 제공한다.

## 실제 AI 사용 전 안내

실제 AI 모드를 처음 이용하기 전에 최근 대화 일부, 선택한 언어·국가가 AI 응답 생성을 위해 Cloudflare Workers 및 Workers AI에서 처리됨을 알리고 명시적으로 동의를 받는다. 동의하지 않아도 데모·로컬 미션을 확인할 수 있게 한다. 동의는 앱이 대화 원문을 외부 처리에 보내는 데 대한 선택이며, 의료적 효과나 모든 법적 요건의 충족을 뜻하지 않는다.

Cloudflare는 명시적 동의 없이 Customer Content를 AI 학습에 사용하지 않는다고 설명한다. 이 정책만으로 모든 접속·보안 메타데이터가 저장되지 않는다고 추론하지 않는다. 실제 운영 전 제공자 정책, 로그 설정, 보존·삭제, 하위 처리자, 처리 국가, 계약 조건을 확인해야 한다. [Workers AI 데이터 사용 정책](https://developers.cloudflare.com/workers-ai/platform/data-usage/)

Turnstile도 실제 AI 요청의 봇 검증을 위해 제공자와 통신한다. 호스팅 제공자는 접속 시 IP 원문을 처리하며, Worker가 읽은 접속 IP는 Turnstile 서버 검증의 `remoteip`로도 전달된다. D1에는 HMAC 가명화 키만 저장한다는 설명을 제공자가 IP를 처리하지 않는다는 보장으로 확대하지 않는다. “기록을 기기에 저장한다”는 설명과 “AI·호스팅·보안 서비스가 데이터를 처리한다”는 설명을 함께 제공한다. 한국·일본 서버에서만 처리되거나 각국 개인정보 법령을 준수한다고 아직 단정하지 않는다.

## 사용자의 제어

| 제어 | 동작·설명 |
|---|---|
| AI 전송 선택 | 실제 AI 사용에 동의하기 전 대화 원문을 모델로 전송하지 않음 |
| 대화 기기 저장 선택 | 대화를 브라우저에 남길지 사용자가 결정. 미션·설정은 기본 로컬 저장임을 별도 안내 |
| 기록 내보내기 | 사용자 기기로 파일 저장. 외부 공유 여부는 사용자가 결정 |
| 모든 기록 삭제 | 현재 앱의 대화·미션 기록을 초기화하고 해당 브라우저 저장 기록 삭제. 다운로드 파일이나 제공자의 이미 처리된 요청까지 소급 삭제한다고 약속하지 않음 |
| 휴식·연기 | 미션 미완료에 불이익·실패 배지·경쟁 순위 없음 |
| 도움 안내 | AI 응답이나 위험 판정 없이 사용자가 직접 공식 안내를 열 수 있음 |

## 대화 안전성

시스템 지침은 짧고 존중하는 응답, 선택권, 진단·약물·치료 지시 회피, 사람의 도움 경로를 지향한다. 하지만 지침만으로 모든 응답의 안전성을 보장할 수 없다. AI가 잘못 말하거나 맥락을 놓칠 수 있다는 사실을 사용자에게 알리고, 한국어·일본어 검토자가 실제 응답을 확인하기 전에는 실사용자 대상 AI 파일럿을 시작하지 않는다.

모델 검토에는 휴식과 거절 수용, 정서적 의존 유도 여부, 의료 질문에 대한 과도한 확신, 개인 식별 정보 요구, 국가에 맞지 않는 도움 정보, 프롬프트 지침 무시 요청을 포함한다. 결과는 모델·프롬프트 버전별로 남긴다. 자동 위기 판정의 정확도나 임상적 효과를 검증했다고 주장하지 않는다.

원격 서비스의 실패·한도 도달을 정서적인 거절로 표현하지 않는다. 기술적 제한임을 명확히 설명하고 미션이나 공식 도움 안내를 계속 확인할 수 있게 한다.

## 국가별 공식 도움 안내

UI 언어와 별도로 이용 국가를 선택하며, 위치 권한이나 IP 추정으로 국가를 단정하지 않는다. 안내는 2026-09-19 공식 페이지를 확인했으며 실제 출시와 정기 점검 시 링크·표시 내용을 다시 확인한다.

| 이용 국가 | 공식 자원 | 앱의 역할 |
|---|---|---|
| 한국 | [보건복지상담센터 자살예방상담전화 109](https://www.129.go.kr/109) — 공식 페이지에서 24시간 상담 안내 | 안내를 제공하며 잇포가 통화·상담 접수 상태를 확인하지 않음 |
| 일본 | [후생노동성 まもろうよ こころ](https://www.mhlw.go.jp/mamorouyokokoro/) — 전화·SNS 등 상담 창구 안내 | 사용자가 필요한 창구를 직접 확인하도록 연결 |

잇포는 도움 링크를 열었다는 사실만으로 구조 요청이나 상담 접수가 완료되었다고 표시하지 않는다. 지정 지원자 알림·기관 연결·응답 추적은 현재 구현 범위 밖이다.

## 실사용자 공개 전 확정할 항목

1. 운영 주체·연락 경로·대상 연령·제공 국가와 서비스 설명.
2. 실제 수집 항목·목적·보유 기간·제공자·처리 국가·사용자 권리 안내 및 필요한 동의 방식.
3. 한국·일본의 개인정보·국가 간 처리 조건, 민감한 대화 처리와 성인 파일럿 운영 절차에 대한 적절한 검토.
4. 제공자 로그 설정과 키 접근 권한, 키 교체·유출 대응, 삭제 절차, 요청량 카운터 만료 처리 검증.
5. 한국어·일본어 사람이 검토한 AI 응답과 도움 문구, 문제 접수·수정·AI 기능 중단 절차.

위 항목을 문서에 적었다는 것과 검토·구현을 완료했다는 것은 구분한다. 완료 근거는 배포 설정, 검증 기록, 운영 결정으로 남긴다.
